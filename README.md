# Final Boss Games
This is a student website for CPW219 to learn the fundamentals of ASP.NET Core MVC (Model View Controller)

## Upcoming features
- Style with Bootstrap 5
- CRUD Functionality (Create/Retrieve/Update/Delete) with Entity Framework Core
- Login/Register
- Shopping Cart

## How to get started
- .NET 10 SDK
- Recommended to use Visual Studio 2026

## Technologies/Frameworks utilized
- ASP.NET Core MVC written in C#
- Entity Framework Core
- Bootstrap 5
- HTML/CSS/JS
